# Movie Editor

開発ビルドのゲーム中に **F6** で開閉します。ゲーム進行と物理を停止し、Deerだけ一時的に非表示にします。
地形は変更しません。ボスがいない場合は制作用の仮ボスを使います。

## キーの編集

- タイムラインのキーをクリックすると、右側の固定パネルに詳細を表示します。
- 右側の「トラック」「キー一覧」からも選択できます。
- 空白をクリックして時刻を指定し、右側の数値を変更すると、その時刻にキーを自動登録します。
- 空白のダブルクリック、＋キーボタン、Kでも登録できます。
- 選択キーの値はその場で更新されます。キーをドラッグすると時刻を移動できます。
- 右クリックメニュー、Deleteで削除、Ctrl+Z/Yで元に戻す・やり直す操作ができます。
- 「1フレーム後に複製」でキーを複製できます。
- 自由カメラを有効にして画面上で右ドラッグ＋WASDQEなどで構図を決め、CameraトラックでKを押すと登録します。
- シーク、±1F、先頭から再生、ループで繰り返し確認できます。

位置はムービー基準位置からの相対座標です。数値キーの補間にはイージングを指定できます。
「このキーでカメラを切り替え」は、その時刻でカメラを切り替えます。
Motionトラックでは既存アニメーション・開始秒・速度・ループを指定します。速度0で指定姿勢を保持します。

## Post Effects

Post Effectsトラックを選択すると、既存のポストエフェクト編集画面を右側に表示します。
露出、ブルーム、色相・彩度・明るさ、カラーグラデーション、放射ブラー、ビネット、色収差、SSAO、FXAAなどをキー登録できます。
数値と色はイージングで補間し、有効/無効・エフェクト方式・サンプル数はキーの時刻で切り替えます。
設定の変更も現在時刻に自動でキー登録され、シーク時もその時刻の設定を再現します。
編集中は戦闘側の一時的な画面演出を重ねず、終了時に元のポストエフェクト設定へ戻します。

## 保存

既定の保存先は `Resources/Movie/BossDefeat.vmovie` です。Ctrl+Sで保存できます。
形式名は `VEER.Movie`、バージョンは2です。カメラ、配置、モーション、Post Effects、QTE受付区間をJSONで保存します。
旧形式の `.vscene` も開けますが、保存は `.vmovie` へ統一します。
基準位置は編集開始時のボスの地面位置（仮ボスならプレイヤーの地面位置）です。基準位置自体は保存しません。
ムービー編集を閉じると配置・ボーン姿勢・Deer表示・カメラ・画面効果を復元します。
未保存の編集は同じゲームシーン内では保持しますが、シーン終了前に保存してください。

QTEはSPACE入力の成否プレビューです。HP・勝敗・必殺技による本番開始条件はまだ接続していません。
ビルド・ゲーム上の操作確認は未実施です。
